## 信号详细分析

### OBCFltLvlIndcn信号分析

- **信号名称**: OBCFltLvlIndcn (OBC故障等级指示)

- **值范围**: 0-7 (其中0表示无故障)
- **位置**: 位47-49 (起始位47，长度3)
- **解析规则**: 1.0倍因子，偏移量0

**故障等级含义**:

- 1-7: 不同的故障等级，数值越高表示故障越严重
